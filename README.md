# Laundry Platform

A SaaS platform for laundries: dormitories, residential buildings and public self-service laundries. IoT sensors report the real state of washers and dryers. Residents find a laundry, see which machines are free, book a slot and start a machine with a code. Technicians handle faults, and laundry admins see machines, faults and utilization.

Course project for IoT and Cloud Computing, Collegium Da Vinci. Work in progress: installation and run instructions will be added when the system is ready.
